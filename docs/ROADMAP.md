# Rash Roads Production Roadmap

## v0.6 — True 3D Foundation (current)
- Modular Vite + TypeScript + Three.js architecture.
- Real 3D traffic and road.
- 3D environmental parallax: terrain, poles, cacti, rocks, mesas, gantries.
- Real lighting/shadow/fog pipeline.
- Preserve tuned traffic/collision behavior.

## v0.7 — Hero Rider Slice
- Replace player proxy with modeled/rigged Rocco.
- Replace starter-bike proxy with reference-matched bike.
- Riding pose, lean, suspension and tail secondary motion.
- Camera/lighting/material polish around hero asset.

## v0.8 — Impact & Recovery
- Wobble and crash animation states.
- High-speed ejection prototype.
- Ground slide and recovery.
- Run-to-bike/remount loop.

## v0.9 — Combat Return
- One rival only.
- Punch/kick range and telegraphing.
- Vehicle-vs-body consequences.
- Combat never compromises traffic readability.
