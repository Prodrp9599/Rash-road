# Rash Roads Visual Bible — v1.2

## North star: Acid Asphalt
Rash Roads is **dimensional stylized 3D**, not flat mascot art. The target blend is believable materials + cartoon readability + grunge-punk attitude.

## Rendering rules
1. Important gameplay objects must be actual 3D geometry.
2. Background objects that create parallax (guardrails, poles, cacti, gantries, rocks, mesas, structures) should also be geometry whenever practical.
3. Avoid full-scene billboard backdrops and large flat cutouts near the road.
4. Use physical depth cues: perspective, contact shadows, cast shadows, atmospheric fog, size falloff, occlusion, and motion parallax.
5. Materials should show depth: rough leather, faded paint, oxidized metal, dusty glass, patched asphalt.
6. Warm world palette; cyan/orange/acid accents are controlled and meaningful.

## Character target
Rocco is adult, compact, athletic and expressive. Real fur volume and facial structure, but simplified enough for high-speed readability. Do not use chibi proportions.

## Environment target
Sun-baked outlaw highway. Worn asphalt, shoulders, guardrails, cacti, utility poles, rocks, distant mesas, occasional gantries/bridges/gas stations/junkyards. Everything should feel placed in one physical world.

## UI
UI can be graphic/grungy because it is intentionally screen-space. It should not contaminate world readability.
